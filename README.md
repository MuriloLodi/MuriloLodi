# 🤖 Destaque: Pact

### Pact — Educação Financeira com IA

SaaS de gestão financeira pessoal com inteligência artificial voltado ao público brasileiro.

🔗 **Produção:** https://usepact.com.br

### Principais funcionalidades

* Dashboard financeiro completo
* Chat com IA em português
* Importação de extratos PDF e CSV
* Metas financeiras automáticas
* Relatórios inteligentes com gráficos
* Múltiplas contas bancárias
* Recorrência de transações
* Planos Free e Premium
* Conformidade com LGPD

### Stack principal

* Next.js + React + TypeScript
* Supabase (PostgreSQL + Auth)
* Groq (Llama 3)
* Anthropic Claude
* TailwindCSS + shadcn/ui
* Vercel + Sentry
